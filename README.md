# 🎯 InVideoQuiz Navigator PRO

Набор userscript'ов для навигации и перебора ответов в интерактивных видео Open edX (InVideoQuiz).

> ⚠️ **Только для разработки и тестирования.** Использование для обхода учебных заданий нарушает политику платформы.

---

## 📦 Версии

| Ветка | Статус | Что умеет |
|-------|--------|-----------|
| 🟢 **LIGHT** | ✅ | Навигация: панель вопросов, перемотка видео, переход к вопросу. Без перебора. |
| 🔴 **HARD** | ✅ | Всё из LIGHT + перебор вариантов с **одним** правильным ответом (radio). |
| 🟣 **EXPERIMENTAL** | 🧪 | Всё из HARD + перебор комбинаций для вопросов с **несколькими** правильными (checkbox). |

### 🚧 В разработке
- Ввод текстового ответа (`input[type="text"]`) — пока не поддерживается.

---

## 🚀 Установка

**Способ 1 — Консоль браузера:**
1. Откройте лекцию → F12 → Console
2. Введите `allow pasting` → Enter
3. Вставьте код нужной версии → Enter

**Способ 2 — Userscript:**
1. Установите [Tampermonkey](https://www.tampermonkey.net/)
2. Создайте скрипт → вставьте код → Ctrl+S

## 🔴 HARD — один правильный

1. Нажмите **🔍 Перебор**
2. Скрипт по очереди выбирает варианты, жмёт Submit, проверяет результат (~800 мс между попытками)
3. На первом правильном — зелёная подсветка, стоп

**Лог:**
```
[QuizNavigator] ✅ SUCCESS Вариант 2 — ПРАВИЛЬНЫЙ!
[QuizNavigator] ━━━ ИТОГ: найдено 1 ━━━
```

---

## 🟣 EXPERIMENTAL — несколько правильных

Генерирует все непустые подмножества N вариантов, сортирует по длине:
```
N=3: [0] [1] [2] [0,1] [0,2] [1,2] [0,1,2]
```
Всего 2ⁿ−1 комбинаций (N=5 → 31, N=10 → 1023).

**После перебора:** восстанавливает правильную комбинацию в UI, подсвечивает зелёным, выводит итоговую плашку.

**Настройки:**
```js
const CONFIG = {
    stopOnFirstCorrect: true,  // стоп на первом успехе
    debug: true,               // логи в консоль
};
```

## ⚠️ Ограничения

- ❌ Вопросы с текстовым/числовым вводом (`input[type="text"]`, `numerical`, `customresponse`)
- ⚠️ При N>6 вариантов checkbox-перебор идёт долго (2ⁿ−1 комбинаций)
- ⚠️ Задержка Submit ~800 мс (зависит от бэкенда)

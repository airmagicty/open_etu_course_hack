# 🎯 InVideoQuiz Navigator PRO v3.1

## 📌 Описание

Скрипт для автоматизированного сканирования и перебора вариантов ответов в интерактивных видео-лекциях Open edX (InVideoQuiz).

> ⚠️ **ВАЖНО**: Скрипт предназначен **ТОЛЬКО ДЛЯ РАЗРАБОТКИ И ТЕСТИРОВАНИЯ**. Использование для обхода учебных заданий нарушает политику платформы.

---

## ✨ Возможности

- 🔍 Автоматическое обнаружение всех вопросов в лекции
- 📋 Панель управления со списком вопросов и их статусами
- 🔄 Перебор вариантов ответов в заданном порядке (2-й вариант → все остальные)
- ⏸️ Пауза и остановка сканирования
- ⏭️ Пропуск вопроса (кнопка "Скип")
- ▶️ Перемотка видео к моменту появления вопроса без остановки воспроизведения
- 👁️ Быстрый просмотр вопроса без перемотки видео
- 📊 Статистика сканирования

## 🚀 Установка

### Способ 1: Консоль браузера

1. Откройте страницу с лекцией
2. Откройте консоль DevTools (F12 → вкладка Console)
3. Если используете консоль впервые, введите `allow pasting` и нажмите Enter
4. Вставьте код из раздела **"Код скрипта"** и нажмите Enter

### Способ 2: Userscript (в разработке)

1. Установите расширение для браузера:
   - **Chrome/Edge**: [Tampermonkey](https://www.tampermonkey.net/)
   - **Firefox**: [Greasemonkey](https://www.greasespot.net/) или [Tampermonkey](https://www.tampermonkey.net/)

2. Создайте новый скрипт и вставьте код из раздела **"Код скрипта"** ниже

3. Сохраните скрипт (Ctrl+S)

- Находит все вопросы
- Создаёт панель управления в левом нижнем углу
- Показывает первый вопрос (без перемотки видео)

### 3. Кнопки управления

| Кнопка | Действие |
|--------|----------|
| **▶ Запустить сканирование** | Начинает автоматический перебор всех вопросов |
| **⏸ Пауза** | Приостанавливает сканирование |
| **⏹ Стоп** | Полностью останавливает сканирование |
| **🔄 Сброс** | Сбрасывает все результаты |
| **◀ Предыдущий** | Переход к предыдущему вопросу с перемоткой видео |
| **Следующий ▶** | Переход к следующему вопросу с перемоткой видео |
| **⏭ Скип** | Пропустить текущий вопрос |
| **📋 Все вопросы** | Показать все вопросы на странице |
| **🔍 Перебор** | Запустить перебор вариантов для текущего вопроса |
| **▶ Перейти** | Перемотать видео к моменту появления вопроса |
| **👁 Показать** | Показать вопрос без перемотки видео |
| **📋 Варианты** | Подсветить варианты ответов в DOM |

### 4. Процесс сканирования

1. **Нажмите** "▶ Запустить сканирование"
2. Скрипт последовательно перебирает варианты:
   - Сначала проверяется **2-й вариант** (индекс 1)
   - Затем все остальные по порядку
3. При нахождении правильного ответа:
   - Вопрос подсвечивается зелёным
   - Появляется уведомление
   - Сканирование останавливается и ждёт вашего решения
4. **Нажмите "⏭ Скип"** чтобы продолжить перебор остальных вариантов
5. После завершения всех вопросов отображается статистика

### 5. Переход между вопросами

- **"◀ Предыдущий"** / **"Следующий ▶"** — перемотка видео к моменту появления вопроса
- **Важно**: Видео **НЕ ОСТАНАВЛИВАЕТСЯ** при перемотке!
